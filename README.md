# Omni Tools 懒猫微服包

一堆常用小工具放在同一个页面里，全部在浏览器本地完成。

- 上游：<https://github.com/iib0011/omni-tools>
- 镜像：`iib0011/omni-tools`
- 许可：MIT（全文见 content/licenses/LICENSE）

## 组成

单容器，容器内监听 80 端口。纯前端工具集合：**无数据库、无持久化需求**。

## 关键配置说明

- **没有账号体系**：工具页无需登录，也不保存任何输入，因此不加 `public_path`，
  访问由懒猫入口鉴权。
- 转换与生成都在浏览器本地进行，敏感文本不会被上传。
- 上游 Docker 说明里对外映射 8080，容器内实际监听 80。
